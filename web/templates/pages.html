Transparency

Trust is verifiable.

Clear boundaries. No invented security guarantees.

Warrant canary unavailable

No signed statement published

This application does not publish a cryptographically signed warrant canary. The absence of a statement is not a claim about legal requests or operational security.

What this application currently does

  • Renders HTML and CSS on the server without requiring client-side JavaScript.
  • Supports account sessions, marketplace listings, and unfunded order drafts.
  • Accepts externally encrypted PGP text for messages. It does not perform browser-side encryption.

What remains unavailable

Bitcoin and Monero funding, wallet balances, multisig escrow, automatic settlement, TOTP, verified PGP ownership, and signed canary publication are not active.
