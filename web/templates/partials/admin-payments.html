Payment providers

Test networks only; the server refuses to start against mainnet and disables a provider whose node later reports mainnet. An unreachable node or a wallet that is not loaded does not stop the site: that currency shows as unavailable, payment requests for it are refused, and the check is retried every poll. Deposits sit in one pooled wallet per currency. There is no commission or fee accounting.

Payouts

Each payout is attempted once. Failed or stuck payouts are never retried automatically: check the wallet before paying anything manually. After checking the wallet you can release a held payout, requeue a payout that was not broadcast, or record one the wallet shows as sent. Each action needs your password and is audited.
