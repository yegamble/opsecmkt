Order wallet.

Order {{.Short}}: the wallet you sign this order's escrow with, made from the seed of your per-order wallet key, for this order only. It is for you, the {{.Own}}, alone; the market shows it to no one else.

Make the wallet

  1. In Electrum with your BIP39 seed (start it with --offline: the order wallet only signs, it never needs a server) or in Sparrow, create a new 2-of-3 multisig wallet, native SegWit (P2WSH).
  2. For your own key, enter the seed of the per-order wallet key you registered, with the derivation path below.
  3. Add the two cosigner keys below as the other two keys (watch-only, or "xpub" cosigners). In Sparrow you can instead import the whole wallet from the descriptor below.
  4. Check that the wallet's first receiving address is the escrow address below. If it is not, stop: the wallet is not this escrow's.

These steps, and the menus they name, have not yet been tried with a real Electrum or Sparrow wallet: the wallet's menus may differ. Hardware wallets have not been tested with per-order escrows.

Signing and afterwards

To sign a settlement, download your copy from the order page, load it into this wallet (in Electrum, Tools › Load transaction › From file; in Sparrow, File › Open Transaction), check its outputs against the order page, sign it without broadcasting it, save it as a PSBT file and upload it on the order page (or paste it there).

Delete the order wallet once the order's escrow has settled (its settlement is confirmed): your seed can make it again from the path above. The escrow address stays watched by the market, so coins sent to it later are returned to the buyer's refund address.
