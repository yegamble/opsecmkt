## Cost categories to retain in the operator record

Record current quotes and billing terms privately rather than embedding one
provider's prices in the deployment procedure. Include:

- Application, upload/scanner and payment compute, with enough memory and disk
  for their actual workloads.
- Managed database capacity, storage, backup retention and recovery options,
  plus any separately approved optional standby.
- Container registry storage and any image-transfer charges.
- VM backup charges, encrypted logical backup storage and retained recovery
  copies.
- Network transfer, monitoring and any separate maintenance-worker capacity.

Review the quote when host sizes, database availability, retained copies or
traffic change. Keep billing activation and successful service verification as
separate facts.
